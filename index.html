Grievance Redressal System

A web-based application that streamlines complaint registration and resolution using Natural Language Processing (NLP), image relevance detection, and location tracking. It provides dedicated interfaces for users and administrators to manage grievances with automated classification, media verification, and real-time status updates.

🌐 Features

  • Automated complaint classification using NLP
  • User portal with a chatbot to submit complaints with images and track status
  • Image relevance checking to verify submitted complaint images
  • Location detection using reverse geocoding for accurate complaint mapping
  • Admin dashboard to view, filter, and update complaint statuses
  • Real-time updates with dynamic visual feedback

🛠️ Tech Stack

  • Python – Backend logic, NLP model, and image validation
  • HTML, CSS, JavaScript – User interface for chatbot and complaint submission, Admin portal and interactive dashboard
  • Flask / FastAPI – REST API development
  • OpenCV / TensorFlow – Image relevance detection
  • Geopy / Google Maps API – Reverse geocoding for location extraction

This project highlights expertise in NLP, computer vision, geolocation services, and full-stack web development to create an intelligent and efficient grievance management system.

SMS/Email Spam Classifier

This project is a Machine Learning-based web application that can detect whether a given SMS or email message is spam or not spam (ham).

🌐 Features

  • Real-time prediction of messages through a user-friendly web interface.
  • Instant feedback on whether the message is likely spam or not.
  • Built with Streamlit for quick and interactive deployment.

🛠️ Tech Stack

  • Python – Core logic and machine learning pipeline
  • Scikit-learn – Model building and evaluation
  • Pandas – Data handling
  • Streamlit – Web app interface
  • Pickle – Model serialization

This project showcases the practical use of machine learning for real-world applications and is ideal for understanding how NLP (Natural Language Processing) can help filter unwanted messages effectively.
